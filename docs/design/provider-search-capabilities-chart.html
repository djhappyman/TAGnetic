General text search remains available on all five current sources. “Wired” describes the backend, not existing chip availability. Classification differs by provider.

Discogs: Native fields; add Label and classification.
MusicBrainz: Documented field syntax; extend our adapter.
Beatport: Release search filters need adapter validation.
Bandcamp: General search works; field filters unverified.
Soundeo: Website facets exist; endpoint support unverified.
GnuDB · future: Artist/album extension documented; no adapter yet.

Identifier column: Discogs/MusicBrainz currently send catalogue number; Beatport documents UPC. These are separate fields. Full citations and limits are in the companion research note.
