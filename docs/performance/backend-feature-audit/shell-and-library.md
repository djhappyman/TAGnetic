## Desktop shell, build, and platform services

| Feature | Rust route and invariant | Verification and remaining evidence |
|---|---|---|
| Start from CLI, app association, or a second launch | `app/src/main.rs`: `paths_from_args`, `hand_over_paths`, `take_launch_paths`. Unix/Windows single-instance callback sends argv and sender directory. MacOS Opened event converts file URLs. Payload-free event with a drain-once queue survives a late listener. | `a_command_line_yields_the_paths_in_it_and_nothing_else`, `an_existing_instance_resolves_arguments_in_the_sender_directory`. Prior behavior used the receiver directory and dropped valid relative paths. Fix resolves from the sender, preserving absolute paths, ordering, invalid and empty argument filtering. Native Linux smoke passed in an isolated webview with a second process launched from a different directory. Windows/macOS launch is source-reviewed. |
| Settings snapshots, defaults, and format/network policy | `load_settings`, `read_settings_recording`, `save_settings_at` in `app/src/main.rs`, `SettingsDto` and `App::apply_settings` in `crates/commands/src/lib.rs`. Validates typed fields, bad JSON notice, unreadable-save refusal, compare-and-swap, unknown-key preservation, settings propagation to provider/Studio and currently active library. | `saved_preferences_reach_a_library_that_is_still_opening`, `desktop_save_preserves_unknown_settings_slices_and_returns_actual_revision`, `stale_desktop_settings_do_not_overwrite_agent_presets`. Themes, shortcut bindings, translations, columns, and sidebar behavior are frontend. Rust persists their settings. Agent-specific settings are covered separately. |
| Atomic settings replacement and recovery | `app/src/settings_store.rs`: `save_with_schema`, `write_replacing`, `preserve_with_stamp`. Read errors, invalid schema, staged write/sync/rename, symlink targets and UNIX modes, recovery copy before replacing. | `a_file_that_is_not_settings_is_kept_before_it_is_replaced`, `a_failed_save_leaves_the_previous_bytes_in_place`, `a_symlinked_settings_file_stays_a_link`, `saving_keeps_the_file_permissions`. External edits in the narrow compare-and-swap/write window and non-Unix power-loss durability merit dedicated tests. |
| Preview work, image fetch admission and long operation ownership | `app/src/blocking.rs` Queue/Latest. `app/src/operation_control.rs` OperationGuard/ImageAdmission. Queue admits before spawning, serializes mutations, keeps running work admitted across caller loss, cancels obsolete read-only previews. Image path caps active workers, waiting async calls are not counted by that active cap. | `a_thousand_obsolete_previews_cancel_while_waiting_and_only_the_last_executes`, `a_dropped_invoker_does_not_release_a_running_workers_permit`, `error_and_panic_release_admission`, `image_permit_survives_caller_abort_and_releases_on_error_or_panic`. Closing the queue or changing image backlog behavior would change timing/acceptance. Measure first. |
| Native file chooser, clipboard, window drag, window geometry | `app/src/main.rs` plugin setup. `app/capabilities/default.json`. `app/src/window_controls.rs`. Plugin commands accessed by main window, saved resize/fullscreen only for main, Linux KDE/GNOME close-button placement and default fallback. | `reads_the_kde_buttons_on_left`, `reads_the_gnome_button_layout`. Chooser/clipboard behavior delegated to native plugins, source only on Windows/macOS here. Audio floating window preferences covered under Studio. |
| Local documents, login window, and app tool IPC boundaries | `app/src/navigation.rs`: `allows`, `development_origin`. Explicit main/tool/login labels, loopback development origin, exact tool document, HTTPS login page, unknown labels refused. Plugin permissions configured per window. | `the_main_window_shows_only_the_documents_the_app_serves`, `an_audio_tool_shows_only_its_own_page`, `only_a_loopback_development_origin_is_trusted`. Tauri app-defined handler checks are separate from plugin permissions and reviewed on each surface. |
| WebKit rendering compatibility | `app/src/webkit_compositor.rs` dynamically resolves version-gated WebKit 2.54 symbols, changes preferences at first load and disconnects restart callback. | Source review. Prior baseline ran `tests/ui/native-rendering.py` on Linux. This patch does not touch those FFI routines. |
| Manual releases and disabled automatic installation | `open_releases_page`, `check_for_update`, `install_update` and `IN_APP_UPDATES` in `app/src/main.rs`, `app/src/update.rs`. Existing personal fork ships versioned downloads, update endpoints short-circuit, no signed auto-update manifest in release workflow. | `personal_release_tags_compare_with_numeric_app_versions`, `the_elevated_installer_is_told_the_folder_last_and_unquoted` cover helper logic. Automatic update delivery remains disabled. Browser and live GitHub installer flow are not exercised by these tests. |
| Packaging, protocols and diagnostics | `app/build.rs`, `app/tauri*.json`, `.github/workflows/{ci,build-release,release,audit,fuzz,output-tests,native-admission-probe,format-fields-ui}.yml`. Release config/lock versions, OS-specific package and audit matrices, debug-only benchmark commands and optional dev bridge. | Local frontend build, Linux workspace tests and lints on the candidate. No pushes, hosted build or remote installer verification for this audit. `library_benchmark_create`, `library_benchmark_query`, `library_benchmark_dispose` are debug hooks with synthetic index and lifecycle. |

## Finding, sorting, searching, and duplicate review

| Feature | Rust route and invariant | Verification and remaining evidence |
|---|---|---|
| Library open, recursive scan, loose/mixed-file drop, recent folders | `open_library`, `open_drop` -> `App::open_drop`, `resolve_drop`, `tagrex_core::scanner::scan`. Explicit set differs from recursive library. Supported extensions and OS junk are filtered, symlinks not followed during walking by default. Recent folders persist through Settings, remove from list is frontend-only. | `finds_supported_files_recursively_and_skips_others`, `picks_up_every_supported_extension_and_ignores_the_rest`, commands drop tests and `read_track_requires_explicit_file_set_membership`. Remaining stress case: denied subtree and externally mounted offline volume. |
| Refresh, read rows, cache and query invalidation | `list_tracks`, `read_track`, `read_track_rows` -> `App::query_snapshot`, `validate_track_paths`, `ReadCache::read`. Unreadable placeholders remain selectable, path scope checked first, policy and file identity gate reuse, successful Apply/Undo refresh or invalidate. | `query_snapshot_reuses_rows_and_tracks_apply_undo_and_refresh`, `unchanged_metadata_read_reuses_the_query_snapshot`, `read_track_does_not_follow_unlisted_symlinks_below_the_root`, `read_track_preserves_the_unreadable_placeholder_contract`. OS identity behavior still needs native platform runs. |
| Search, nested groups, missing values, numerical ranges, regex and credits | `library_query` -> `QueryIndex::query`, `CompiledQuery`, `query_members.rs`. Snapshot is immutable and cancellation includes invalidation. Malformed regex/unknown operators fail instead of broadening. Groups/selection in displayed table also use frontend state. | `nested_groups_multivalues_and_ranges`, `unknown_fields_and_bad_regex_do_not_broaden`, `indexed_conditions_match_row_evaluation_for_all_operators`, `artist_and_genre_members_are_exact_deduplicated_and_suggested`. Native query sort handles numeric ordering and stable fallback. Natural filename/folder display sorting and manual table order are frontend concerns. |
| Suggestions, search chips, saved presets, phrases | `library_suggest` -> `QueryIndex::suggest`, `facet`, `member_facet`, field resolver. Filters and limits preserved. Frontend chips/phrase interpretation produce query model, Rust performs matching. Settings and MCP presets provide persistence/CAS. | `facets_respect_existing_filters`, `field_suggestions_combine_credits_once_and_preserve_typed_contains_term`, `absent_scope_candidates_are_remembered_and_the_memo_stays_bounded`, `hot_high_cardinality_facets_stay_resident_across_suggestions`. Some cache tests are opt-in pressure probes. |
| Calculated columns, query overlays, virtual table data | `render_column`, `render_columns` -> masks and `QueryIndex::custom_index`. Base rows shared. Overlays and cache retained bytes charged. Payload includes path manifest once per snapshot. Column configuration, selection counts and virtualization live in frontend. | `custom_tags_and_mask_columns_use_lossless_keys_and_cached_values`, `computed_saved_snapshot_overlay_keeps_retained_admission_until_last_owner`, `base_query_rows_retain_charged_ownership_until_snapshot_drop`. Existing 100k library artifacts are historical, no fresh time guarantee. |
| Exact copies | `library_duplicates_start/status/cancel`, `find_duplicates` -> `duplicates::scan_with_updates`: size candidate, SHA-256, complete byte confirmation and stamp revalidation. Read-only. | `exact_hash_candidates_are_confirmed_with_bytes`, `equal_size_and_even_colliding_hash_candidates_never_publish_false_groups`. Re-stat before publishing. |
| Same audio and likely recording | Same duplicate job entry, full PCM hash with format layout, bounded prefix fingerprint/duration/version gates for likely, partial groups only when verified. DB/cache persists only in memory. | `full_audio_comparison_ignores_container_metadata`, `likely_partial_groups_require_every_pair_and_keep_their_id`, `local_transcoding_check_finds_same_recording_across_encodings` (opt-in). Large-library cache currently clears its entries at 4,096, and native Windows duplicate stamps use size/mtime. Evaluate exact file identity and repeated scan behavior together. |
| Duplicate progress, cancellation, and companion queries | `DuplicateJob` in `app/src/main.rs`, `GroupProgress` and query duplicate modes. Jobs bound to snapshot/generation, invalidated/late results declined, no deletion. | `duplicate_job_cancel_clears_partial_groups_and_rejects_late_publication`, `running_duplicate_groups_supply_partial_queries_facets_and_total_group_count`, `duplicate_filter_retains_companion_files`. Presentation of differences is frontend. |
| Trash | `trash_files` -> `App::trash_files` and OS Trash backend. Validate library scope before moving, invalidate affected query results, intentionally separate from Apply/Undo. MCP requires explicit grant and confirmation. | Linux native smoke moved one disposable WAV into the private profile's OS Trash. Batch partial failure and the Windows/macOS Trash paths remain separate coverage gaps. |
