# Local agent service and MCP feature audit

Baseline `1d8ac26e`. Each row records the route and the contract inspected. Test identifiers denote the relevant existing regression unless the row says gap. See the execution record below for which tests ran in this pass. The desktop routes require the main Tauri window. Service calls first check enabled state, principal epoch/expiry and read grant, check the 1 MiB arguments limit, and recheck read authority plus response size before returning.

File keys in the routes and evidence columns are relative to the repo. S is `crates/service/src/lib.rs`, D is `crates/service/src/domains.rs`, P is `crates/service/src/plans.rs`, O is `crates/service/src/outputs.rs`, G is `crates/service/src/staging.rs`, and A is `app/src/mcp_control.rs`. Unqualified service test names are in `crates/service/src/tests.rs`. Integration tests and platform/runtime gaps are qualified where useful.

## Findings and dispositions

- **Pairing after storage failure.** A failed `clients.json` write left a newly allocated, unreachable client record in the in-memory grant table. Discard the tentative record only if atomic replacement fails before publication. If replacement is visible but parent sync fails, retain memory alignment with the visible copy and report the durability error without giving out a credential. The regression makes the private fixture destination unavailable, keeps the prior registry and credential, restores the fixture, and retries. On Unix a separate fixture verifies that a post-publication sync failure leaves the new file visible.
- **Analysis worker terminal state.** Unlike durable write workers, read-only analysis workers could unwind without retiring the running state. Treat an unexpected panic as an analysis failure and retain terminal notification and safe release. The regression uses a synthetic WAV and an in-process BPM adapter.
- **Transport shutdown under slow delivery.** A connection continues to hold an instance lease until its reply finishes. The host has input deadlines, whereas the reply writer can remain pending. Keep operation persistence independent of egress and measure local/Windows named-pipe behavior before choosing a shutdown or delivery deadline. This is source evidence.
- **Administrative persistence.** Enable and revoke deliberately update runtime state before persistence. On failing storage, durable confirmation is unavailable. Revisit failure semantics explicitly for enable and especially revoke, with an exercise of restart from private profile snapshots. This is distinct from safely removing a new unreturned pairing.
- **Large service lifecycle.** `operations.status` listing can exceed the wire cap because retained receipts may number 10,000. Single receipt polling stays available.
