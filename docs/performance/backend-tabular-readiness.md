# Native tabular import checkpoint

Implementation base: `9da71249`, foundation branch, 18 November 2026. Parent-owned
implementation: `commands/tabular.rs`, registration and assignment-engine access,
service tool/catalog integration, independent CSV fixture and this guide/evidence.
The full backend programme remains open; this is not UI or platform completion.

The strict streaming-record parser retains one parsed record at a time. Mapping,
matching and plan generation use the shared native field engine. See
[semantics and limits](../guide/tabular-imports.md). The independent fixture was
generated by Python's standard `csv.writer` with seed 20261118, 300 records,
five columns, CRLF boundaries, and a pool containing empty cells, whitespace,
commas, tabs, quotes, LF/CRLF, Unicode and formula-looking plain text. The saved
JSON contains both producer CSV bytes/text and the original expected cells.

## Evidence before shared-admission follow-up

The targeted suite passed twelve tests including two explicitly invoked manual
probes. The normal tests include the independent Python corpus, all 78,125
length-seven strings over a hostile quote/delimiter/newline alphabet, 100,001
record pressure, per-cell/column limits, cancellation during a large record,
mapping expansion, explicit empty policies, ambiguous/duplicate destinations,
Unicode/UTF-16, stage composition and restart/Undo.

The explicit media probe generated short MP3, FLAC and M4A audio with FFmpeg.
FFprobe independently verified Unicode titles, multiline comments and retained
artist values after Apply; preview left file bytes untouched. Encoded audio
packet SHA-256 lists remained identical after Apply and reopened-journal Undo.
Selected original metadata was restored. This does not prove byte-identical
container rewrites or every damaged/third-party variant.

A manual pressure probe created 10,000 synthetic tiny WAV files, matched a
reverse-ordered CSV by filename and verified the first/last intended titles on
six complete previews. First preview: 452.004 ms; five warm previews:
54.623/55.531/53.344/50.056/48.715 ms. Input: 287,792 bytes. Retained metadata charge:
10,606,670 bytes. The probe checked no transient/job charge remained after each
preview and all cache charges returned to their baseline after App drop. It
performed no audio writes. These are native preview timings, excluding UI/IPC,
Apply/journal, cold-disk evidence and a baseline speedup comparison. Fixtures are
deleted by their task-owned fixture guard.

Two service composition tests passed: table import can revert a staged field
without removing another field; malformed/duplicate-row attempts leave the live
stage unchanged; explicit encoded-byte input supports UTF-16; incorrect input
kind/encoding is refused.

Shared-admission integration and subsequent changes require fresh targeted and
combined gates. Independent adversarial review is pending. Do not interpret the

## Corrections and latest targeted gate

The separate review reproduced skipped cancellation checkpoints: quoted escapes
and CRLF can advance by two bytes and never hit an absolute modulo boundary.
Parsing now uses a monotonic next-offset threshold and checks blank-line skipping
as well. Both unchanged-intent reviewer canaries passed after this correction.

The parent also added inherited worker-local preview cancellation. Its first
real legacy-preview canary failed: filename extraction swallowed the cancelled
read as an unreadable file and returned a shortened plan. Explicit checks now
abort those legacy loops. Scope nesting, unwind restoration and thread isolation
passed their targeted three-test run. Ordinary mutation queues do not acquire
this preview context.

canaries. Latest 10,000-file first preview was 454.692 ms, five warm previews
53.835/54.119/55.910/53.494/52.392 ms, with the same 10,606,670-byte metadata
charge and no leaked transient/job charges. The media probe again passed.
